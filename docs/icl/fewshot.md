 ## FewShot

- **Модуль**: [`FewShot`](../../src/icl/fewshot/fewshot.py)
- **Оригинальная статья**: [Language Models are Few-Shot Learners](https://arxiv.org/pdf/2005.14165.pdf)

---

## Принцип работы

Реализует выбор **k наиболее информативных few‑shot демонстраций** для in‑context learning по мотивам анализа перплексии, близкий по духу к идее из GPT‑3‑статьи: модель использует несколько примеров в контексте, чтобы улучшить качество ответа без дообучения.

В данной реализации `FewShot`:

- оценивает, насколько один пример помогает языковой модели лучше предсказывать другие,
- используя для этого разницу перплексий с этим примером в контексте и без него,
- суммирует такой вклад по всем остальным примерам,
- выбирает `k` примеров с наибольшим суммарным вкладом.

На выходе блок возвращает список из `k` `Chunk`, которые стоит использовать как демонстрации в few‑shot промпте.

---

## Параметры инициализации

- `url: str` — `base_url` для OpenAI‑совместимого API (в проекте ожидается локальный `vllm`‑сервер).
- `model_name: str` — название LLM, используемой для расчёта перплексии.
- `k: int = 5` — количество примеров, которые нужно отобрать как few‑shot демонстрации.

---

## Алгоритм

Для выбора демонстраций вызывается `FewShot.apply(chunks: List[Chunk])`:

1. **Проверка граничных случаев**
   - Если список `chunks` пуст — возвращается пустой список.
   - Если `k >= len(chunks)` — возвращаются все примеры как есть, без отбора.

2. **Подсчёт перплексии**
   - Вспомогательный метод `_ppl(prompt: Text)` отправляет текст в LLM:
     - `completions.create(model=self.model_name, prompt=prompt, max_tokens=100, logprobs=True)`.
     - По массиву `token_logprobs` считается:
       - средний отрицательный логарифм вероятности (энтропия),
       - перплексия как \(\exp(\text{entropy})\).

3. **Оценка вклада одного примера в предсказание другого**
   - `_score_pair(ctx: Chunk, target: Chunk)`:
     - считает перплексию `ppl_base` на тексте `target.text`;
     - считает перплексию `ppl_cond` на конкатенации `ctx.text + "\n" + target.text`;
     - возвращает разность `ppl_base - ppl_cond`:
       - чем сильнее падает перплексия при добавлении `ctx` в контекст, тем полезнее `ctx` для предсказания `target`.

4. **Информативность примера относительно всего набора**
   - `_score_single(chunk: Chunk, all_chunks: List[Chunk])`:
     - берёт все остальные примеры `others = all_chunks \ {chunk}`;
     - суммирует `self._score_pair(chunk, t)` по всем `t` в `others`;
     - итоговый скор показывает, насколько данный пример помогает модели правильно предсказывать **остальные** примеры датасета.

5. **Выбор k лучших демонстраций**
   - Для каждого `chunk` считается `score = _score_single(chunk, chunks)`.
   - Получается список `(score, chunk)` по всем входным примерам.
   - Список сортируется по убыванию `score`.
   - Берутся первые `k` примеров с наибольшим скором:
     - `best = [chunk for _, chunk in scores[:self.k]]`.
   - Возвращается `best` как итоговый набор few‑shot демонстраций.

---

## Замечания

- В статье GPT‑3 few‑shot обучение реализуется за счёт простого добавления нескольких демонстраций в контекст без дообучения параметров.
- Реализация `FewShot` в проекте формализует шаг выбора таких демонстраций: примеры, которые сильнее всего снижают перплексию модели на других примерах, рассматриваются как наиболее информативные и используются в качестве few‑shot контекста.
