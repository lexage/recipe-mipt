## Принцип работы

Реализует идею **In-Context Curriculum Learning (ICCL)**: демонстрации в промпте упорядочиваются от **простых к сложным**, чтобы улучшить in‑context learning без дообучения модели.

В данной реализации сложность (difficulty) каждого примера оценивается через **перплексию LLM на этом примере**: чем ниже перплексия, тем "легче" пример.  
Блок `ICCL`:

- вычисляет перплексию для каждого входного `Chunk`,
- сортирует примеры по возрастанию перплексии (от простых к сложным),
- возвращает отсортированный список `Chunk`, который затем можно использовать как демонстрации в промпте.

Это соответствует ключевой идее ICCL из статьи: **curriculum‑упорядочивание демонстраций по сложности, измеренной перплексией**.

---

## Параметры инициализации

- `url: str` — `base_url` для OpenAI‑совместимого API (в проекте ожидается локальный `vllm`‑сервер).
- `model_name: str` — имя LLM, используемой для расчёта перплексии и оценки сложности примеров.

---

## Алгоритм

Для упорядочивания примеров вызывается метод `ICCL.apply(chunks: List[Chunk])`:

1. **Оценка сложности примеров**
   - Для каждого `chunk` вызывается `_eval_example(chunk.text)`:
     - к LLM отправляется запрос `completions.create` с:
       - `model=self.model_name`,
       - `temperature=0`,
       - `prompt=example` (текст примера),
       - `max_tokens=100`,
       - `logprobs=True`.
     - по массиву `token_logprobs` вычисляется:
       - средний отрицательный логарифм вероятности (энтропия),
       - перплексия как \(\exp(\text{entropy})\).
   - Если значение перплексии определено и больше нуля, пара `(chunk, perplexity)` попадает в список валидных примеров.

2. **Curriculum‑упорядочивание**
   - Список валидных пар `(chunk, perplexity)` сортируется по возрастанию перплексии:
     - **меньшая перплексия → пример проще**, поэтому он должен идти **раньше** в последовательности демонстраций.

3. **Формирование результата**
   - Возвращается список `Chunk` в порядке, определённом сортировкой по перплексии.
   - Этот порядок можно непосредственно использовать при формировании few‑shot промпта: сначала более простые примеры, затем более сложные.

## Замечания

- В статье ICCL сложность демонстраций на уровне экземпляров предлагается измерять именно через **перплексию** модели на целевой метке/ответе, а затем сортировать примеры от "лёгких" к "сложным".
- Текущая реализация следует этому принципу, оценивая сложность текста примера по перплексии и используя получённый порядок как curriculum для in‑context learning.
