# Агенты для генерации

Агенты для генерации синтетических данных можно разделить на два типа:
- **Тип - Пре-инференс**: Могут применяться на этапе формирования БД. Они принимают список всех документов, которые есть в БД и генерируют список синтетических документов. Для этого типа был написан базовый класс Generator с соответсвующим методом `def generate(self, documents: List[Document]) -> List[Document]`. 
- **Тип - Инференс**: Применяются, на этапе инференса, когда известен запрос. Например: Перефразирование запроса в RAG или Перефразирование самой задачи.

## Базовые классы, используемые для генерации (Тип - Пре-инференс)

### Generator

Все агенты генерации соответствуют данному классу и принимают на вход список документов из БД (документы или примеры кода, в зависимости от задачи), а на выход дают также список документов, но уже синтетических, созданных агентом.

```python
    class Generator(Block):
        """Base class for synthetic document generators."""

        @abstractmethod
        def generate(self, documents: List[Document]) -> List[Document]:
            """Generate synthetic documents from input documents.

            Args:
                documents (List[Document]): Optional source documents used to guide generation.

            Returns:
                List[Document]: Generated synthetic documents.
            """
            raise NotImplementedError
```
### Text

Аналог str. Используется для обозначения, что это не просто строковая переменная, а что-то на вход или выход LLM.

```python
Text = str
```

### Metadata

Mapping для метаданных, где:
- ключи должны быть строками
- значения могут быть любого типа

```python
Metadata = Mapping[str, Any]
```

### Document

Класс документа для взаимодействия с БД. Используется как для хранения существующих документов из базы данных, так и для создания новых документов перед добавлением в БД.

```python
class Document:
    id: str
    text: Text
    source: str  # e.g. 'github', 'stackoverflow', 'forum'
    metadata: Metadata = field(default_factory=dict)
```

## Описание агентов для генерации

Для инициализации каждого агента генерации используются следующие аргументы:
- `url` — URL VLLM сервера (опционально)
- `model_name` — название LLM модели (опционально)
- `prob` — вероятность обработки документа (0.01 = 1%)

### RandomWordGenerator

- `Краткое описание`: Агент генерации кода. Первым шагом он придумывает задачу по программированию и оформляет ее, как промпт для LLM. В сгенерированном промпте, всегда присутствую 3-5 обязательных слов, выбранных случайным образом из списка. Затем модели передается этот промпт для решения задачи, а также экземпляр документа из БД, как пример.
- `Настройки генерации`: 
    - Температура генарции промпта: 0.6 (для креативности)
    - Температура генерации кода: 0.1 (для точности)
    - Максимум токенов: 500
    - Случайные слова: 3-5 штук на документ
- `Тип используемых документов их БД`: Примеры кода
    ```
    DOCUMENT_SRC_EXAMPLES = 'examples'
    ```

### RandomTopicGenerator
- `Краткое описание`: Агент генерации документации. Выбирает случайную тему из фиксированного списка и создает пример документации по этой теме, используя существующий документ как образец стиля и формата.
- `Настройки генерации`:
    - Температура: 0.1
- `Тип используемых документов их БД`: Документация
    ```
    DOCUMENT_SRC_DOCUMENTS = 'documents'
    ```

### ZeroShotGenerator
- `Краткое описание`: Агент генерации документации без примеров (zero-shot). Создает документацию по любой библиотеке Python без использования конкретных примеров из БД.
- `Настройки генерации`:
    - Температура: 0.6
- `Тип используемых документов их БД`: Документация
    ```
    DOCUMENT_SRC_DOCUMENTS = 'documents'
    ```

### OneShotGenerator
- `Краткое описание`: Агент генерации документации с одним примером (one-shot). Создает документацию по любой библиотеке Python, используя один пример из БД как образец стиля, но не копируя его содержание.
- `Настройки генерации`:
    - Температура: 0.3 (баланс между креативностью и соответствием стилю)
- `Тип используемых документов их БД`: Документация
    ```
    DOCUMENT_SRC_DOCUMENTS = 'documents'
    ```

### InstructGenerator

- `Краткое описание`: Агент генерации инструкций и кода. Сначала создает промпт для LLM на основе примера кода, затем использует этот промпт для генерации нового кода.
- `Настройки генерации`: 
    - Температура генарции промпта: 0.6 (для креативности)
    - Температура генерации кода: 0.1 (для точности)
- `Тип используемых документов их БД`: Примеры кода
    ```
    DOCUMENT_SRC_EXAMPLES = 'examples'
    ```

### CodeEvalGenerator

- `Краткое описание`: Агент усложнения примеров кода. Повышает сложность существующих примеров из документации, добавляя новые требования, ограничения и шаги решения.
- `Настройки генерации`: 
    - Температура: 0.1
    - Максимум токенов: 500
- `Тип используемых документов их БД`: Примеры кода
    ```
    DOCUMENT_SRC_EXAMPLES = 'examples'
    ```

## IncorrectExampleGenerator

- `Краткое описание`: Агент генерации некорректных примеров кода. Создает версии примеров с семантическими ошибками, которые компилируются, но содержат логические баги.
- `Настройки генерации`: 
    - Температура: 0.1
- `Тип используемых документов их БД`: Примеры кода
    ```
    DOCUMENT_SRC_EXAMPLES = 'examples'

## QueryGenerator

- **Краткое описание**: Генерирует перефразировки для запроса в RAG
- **Насткройки генерации**:
    - `options` - Количество генерируемых перефразировок. 
- **Пример**:
    ```python
    agent = QueryGenerator(url="<your url>", model_name="<your model name>", options = 3)
    queries = agent.run("What is numpy").split("\n")
    ```
