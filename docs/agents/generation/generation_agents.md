# Описание агентов для генерации

## RandomWordGenerator

- `Краткое описание`: Агент, перефразирующий запрос пользователя и выдающий ответ на новый запрос. Запрос перефразируется не просто через LLM, а с добавлением 3-5 случайных слов из подготовленного списка. Агент нужен для расширения выборки ответов, за счет увеличения разнообразия запросов.
- `Вход`:
    - Запрос
    - Пример
- `Выход`:
	- Ответ модели (Решение перефразированной задачи)

## InstuctGenerator

- `Краткое описание`: Агент, получающий пример кода и дающий в ответе вариант промпта для получения такого ответа
- `Вход`:
    - Пример
- `Выход`:
	- Промпт для получения ответа аналогичного тому, что дан агенту в примере

## ZeroFewShotGenerator

- `Краткое описание`: Агент, формирующий три ответа: решение задачи (используя пример и без него), новый запрос на случайную тему из заранее подготовленного списка.
- `Вход`:
    - Запрос
    - Пример
- `Выход`:
    - Решение задачи из запроса (без примера)
    - Новый запрос, на случайную тему из заранее подготовленного списка
    - Решение задачи из запроса (с примером)

## CodeEvalGenerator

- `Краткое описание`: Агент, генерирующий более сложную версию кода из примера
- `Вход`:
    - Решенная задача
- `Выход`:
	- Решенная усложненная версия исходной задачи и ее краткое описание

## IncorrectExampleGenerator

- `Краткое описание`: Агент, генерирующий варианты ошибочных решений
- `Вход`:
    - Задачи
- `Выход`:
	- Неправильное решение задачи

## QueryGenerator

- `Краткое описание`: Агент, предлагающий заданное количество вариантов перефразирования исходной постановки задачи. Дефолтное значение количества вариантов - 3.
- `Вход`:
    - Количество нужных формулировок задачи
    - Задача
- `Выход`:
	- Перефразированная задача (версия 1)
	- Перефразированная задача (версия 2)
	- ...
	- Перефразированная задача (версия N)
