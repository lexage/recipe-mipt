## PANEL (Dancing with Critics)

### `Статья` https://arxiv.org/pdf/2503.17363

### `Описание`

Агент одновременно создает несколько решений задачи. Далее для каждого созданного такого решения генерируется его критика. Далее с помощью полученных критических анализов решений выбирается одно лучшее решение. И агент возвращает это решение.

### `Запуск`

- Для запуска агента его необходимо сначала импортировать в файл.

```
from src.agents.pipelines import Panel
```

- Далее необходимо создать агент:

```
agent = Panel(
    name: str = "Panel",  # название агента
    model_name: str = "Qwen/Qwen1.5-32B-Chat-AWQ",  # название используемой LLM
    openai_api_base_url: str = "http://localhost:7215/v1",  # url развернутой LLM
    temperature: float = 0.6,  # температура LLM
    num_candidates: int = 5,  # кол-во кандидатов при семплировании
)
```


- Далее вызвать агент с помощью метода run и получить решение:

```
critic = agent.run(task, context)

Где: task: str - задача,
     context: str - контекст задачи
```
