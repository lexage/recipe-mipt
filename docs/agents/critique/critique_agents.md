# Описание агентов для критики

## CRITIC

- `Статья` https://arxiv.org/pdf/2305.11738

- `Описание`

Агент-критик находит ошибки в коде, используя инструменты. Сейчас реализованы следующие инструменты: компилятор кода на питоне, поиск в интернете. Агент находит ошибки за несколько шагов: сначала получает результат имплементации входного кода, затем сравнивает полученный результат с ожидаемым результатом, после чего генерирует критику имплементации.

- `Запуск`

## Self-Refine

- `Статья` https://arxiv.org/pdf/2305.11738

- `Описание`

Агент-критик находит ошибки в коде, используя только few-shot примеры решения аналогичных задач. Примеры содержат формулировку задачи, имплементацию на питоне (решение задачи) и критику имплементации.

- `Запуск`



## Reflexion

- `Статья` https://arxiv.org/pdf/2303.11366

- `Описание`

Агент-критик находит ошибки в коде, используя отдельный шаг оценки. Сначала агент генерирует численную оценку от 1 до 5 входной имплементации кода, затем генерирует критику имплементации, используя численную оценку.

- `Запуск`
