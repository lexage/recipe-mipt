# Описание агентов для критики

## CRITIC

### `Статья` https://arxiv.org/pdf/2305.11738

### `Описание`

Агент-критик находит ошибки в коде, используя инструменты. Сейчас реализованы следующие инструменты: компилятор кода на питоне, поиск в интернете. Агент находит ошибки за несколько шагов: сначала получает результат имплементации входного кода, затем сравнивает полученный результат с ожидаемым результатом, после чего генерирует критику имплементации.

### `Запуск`
- Для запуска агента его необходимо сначала импортировать в файл.

```
from src.agents.critique import Critic
```

- Далее необходимо создать агент:

```
agent = Critic(
    name: str = "CRITIC",  # название агента
    model_name: str = "Qwen/Qwen1.5-32B-Chat-AWQ",  # название используемой LLM
    openai_api_base_url: str ="http://localhost:7215/v1"  # url развернутой LLM
)
```

- Далее вызвать агент с помощью метода run и получить критику:

```
critic = agent.run(problem, answer)

Где: problem: str - задача,
     answer: str - предложенное решение
```

## Self-Refine

### `Статья` https://arxiv.org/pdf/2305.11738

### `Описание`

Агент-критик находит ошибки в коде, используя только few-shot примеры решения аналогичных задач. Примеры содержат формулировку задачи, имплементацию на питоне (решение задачи) и критику имплементации.

## Reflexion

### `Статья` https://arxiv.org/pdf/2303.11366

### `Описание`

## DeCRIM

### `Статья` https://arxiv.org/pdf/2410.06458

### `Описание`

Агент-критик находит ошибки в коде путём декомпозиции следующим образом: из исходной инструкции выделяется несколько ограничений, затем агент проверяет решение на соответствие каждому ограничению и возвращает критику решения.
