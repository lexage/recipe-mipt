# Automatic Chain-of-Thought

- **Модуль**: [`AutoCoT`](../../../src/agents/reasoning/autocot/main.py)
- **Cтатья**: [AUTOMATIC CHAIN OF THOUGHT PROMPTING IN LARGE LANGUAGE MODELS](https://arxiv.org/pdf/2210.03493)
- **Официальный репозиторий**: [GitHub](https://github.com/amazon-science/auto-cot)

---

## Принцип работы

Автоматически создает демонстрационные примеры для цепочки рассуждений. 

* С помощью `Sentence-BERT` получаются эмбеддинги вопросов, которые кластеризуются с использованием алгоритма `k-means`. 

* Внутри каждого кластера вопросы сортируются по их близости к центру. Берется ближайший к центру кластера вопрос. 

* Для рассматриваемого вопроса модель генерирует цепочку рассуждений методом CoT Zero-Shot. Есть два сценария генерации цепочки рассуждений: когда правильный ответ известен, и когда нет. Если вопрос и соответствующее ему рассуждение не удовлетворяют эвристикам, берется следующий по близости к центру кластера вопрос и тд. 

* Сформированные таким образом примеры добавляются в промпт для генерации рассуждения как демонстрационные.

## Параметры инициализации

- `problems: Union[str, List[Dict[str, str]]]` - путь до файла с вопросами (и ответами) в формате `jsonl` или список словарей с ключами `"question"` (текст вопроса) и `"code"` (верное решение, опционально); 
- `name: str = "AutoCoT"` - имя агента;  
- `model_url: str = "http://localhost:7215/v1"`;
- `model_name: str = "Qwen/Qwen1.5-32B-Chat-AWQ"`;
- `embed_url: str = "http://localhost:7216/v1"`;
- `embed_name: str = "Qwen/Qwen3-Embedding-4B"`;
- `temperature: float = 0`.

## Работа со скриптами

Является наследником класса Agent. Пример использования:

```
from src.agents.reasoning.autocot.main import AutoCoT

reasoner = AutoCoT("src/agents/reasoning/autocot/examples_with_code.jsonl")
solution = reasoner.run(task, num_demos=5)
```

Здесь `task: str` - текстовое описание задачи, `num_demos: int = 4` - количество демонстрационных примеров, которые будут получены. 

Основной метод - `run` - возвращает решение задачи (`str`).
