# Selection-Inference

- **Модуль**: [`SelectionInference`](../../../src/agents/reasoning/selection_inference/main.py)
- **Cтатья**: [Selection-Inference: Exploiting Large Language Models for Interpretable Logical Reasoning](https://arxiv.org/pdf/2205.09712)

---

## Принцип работы

Разбивает процесс рассуждения на два этапа: 

* **Selection**: модель выбирает из контекста ограниченный набор фактов, достаточный для совершения ровно одного шага рассуждения.

* **Inference**: модель, опираясь исключительно на эти выбранные факты и не имея прямого доступа к исходному вопросу, генерирует новое промежуточное утверждение. 

Процесс повторяется циклично: каждый новый факт добавляется обратно в контекст, становясь доступным для последующих итераций, пока не будет достигнуто максимальное число шагов алгоритма. 

---

## Параметры инициализации

- `selection_examples: str` - строка с примерами для этапа Selection или путь до файла с ними в формате `jsonl`. Файл должен содержать ключи `"context"` (контекст, из которого будут извлекаться факты), `"question"` (текст вопроса) и `"selection"` (набор релевантных вопросу фактов, выбранных из контекста); 
- `inference_examples: str` - строка с примерами для этапа Inference или путь до файла с ними в формате `jsonl`. Файл должен содержать ключи `"selection"` (набор фактов) и `"inference"` (утверждение, выведенное на основе этих фактов); 
- `name: str = "SelectionInference"` - имя агента; 
- `selection_mode: str = "simple"` - метод выбора фактов на этапе Selection. Есть две опции: `"simple"` и `"scoring"`.   
    * Simple подход: показать модели несколько примеров и явно попросить ее сгенерировать необходимые факты;
    * Scoring подход: для каждого факта в контексте получить оценку его логарифмического правдоподобия, добавить факт с максимальной оценкой к выбранным фактам и в контекст, повторять процесс, пока не наберется нужное количество фактов;
- `max_steps: int = 5` - число итераций алгоритма.

---

## Работа со скриптами

Является наследником класса Agent. Пример использования:

```
from src.agents.resoning.selection_inference.main import SelectionInference

reasoner = SelectionInference(
    "selection_examples.jsonl",
    "inference_examples.jsonl",
    selection_mode="simple",
    max_steps=5
)
solution = reasoner.run(context, question)
```

Здесь `context: str` - контекст, из которого берутся факты, `question: str` - текстовое описание вопроса. 

Основной метод - `run` - возвращает рассуждение (`str`) как цепочку шагов Selection-Inference.
