- **Cтатья**: [Data Selection for Language Models via Importance Resampling](https://arxiv.org/pdf/2302.03169)
- **Официальный репозиторий**: [GitHub](https://github.com/p-lambda/dsir)

## Принцип работы

- На первом этапе сырые и целевые данные переводятся в пространство признаков низкой размерности, чаще всего в виде хешированных n-грамм.
-  Для каждого набора данных строится простая генеративная модель «мешка n-грамм». Параметры этих моделей оцениваются подсчетом частот появления признаков.
- Для каждого примера из сырого набора данных рассчитывается вес значимости. Этот вес представляет собой отношение вероятности появления конкретных признаков в целевом распределении к вероятности их появления в сыром распределении.
- На основе вычисленных весов из исходного массива выбирается необходимое количество примеров методом сэмплирования без замены (с применением Gumbel top-k trick).
- Вероятность выбора каждого фрагмента пропорциональна его весу. Это гарантирует, что итоговый набор данных будет по своим статистическим характеристикам соответствовать целевому распределению.

## Аргументы функции

- `raw_chunks: List[Chunk]` - список сырых чанков (для фильтрации);
- `target_chunks: List[Chunk]` - список целевых чанков (к чему стремимся);
- `num_to_sample: int` - число чанков, которое будет отобрано; 
- `num_proc: Optional[int] = None` - количестов ядер CPU для распараллеливания. Если `None`, используются все доступные ядра;
- `ngrams: int = 2` - $N$ в $N$-граммах. 2 означает как униграмму, так и биграмму;
- `num_buckets: int = 10000` - количество бакетов для хэширования $N$-грамм;
- `tokenizer: str = 'word_tokenize'` - используемый токенизатор;
- `min_example_length: int = 100` - минимальное количество токенов в рассматриваемом примере;
- `num_tokens_to_fit: Union[str, int] = 'auto'` - настраивает объем данных, на которых будет обучаться модель весов значимости. При значении `auto` автоматически выбирает количество токенов (`100k * num_buckets`). При значении `all` модель обучается на полном объеме предоставленных данных. При передаче целого числа обучается на таком количестве токенов. 
- `top_k: bool = False` - если `True`, выбирает $k$ документов с наибольшими оценками весов вместо сэмплирования.


## Работа со скриптами

Установка:

```
!pip install data-selection
```

Разбиение на чанки, описанное в статье, реализовано в [DSIRChunker](../../src/agent_constructor/chunkers.py). Авторы разбивали документы на чанки фиксированной длины, используя токенизацию по пробелам.


Пример использования:

```
from src.filtering.dsir.main import dsir_pipeline

filtered_chunks = dsir_pipeline(raw_chunks, target_chunks, num_to_sample)
```

Возвращает `List[Chunk]`. Также сохраняет отобранные чанки в `"src/filtering/dsir/resampled"`.
