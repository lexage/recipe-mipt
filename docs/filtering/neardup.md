## Принцип работы

В основе работы метода лежит алгоритм MinHash, который преобразует текст в наборы $n$-грамм и оценивает сходство документов через коэффициент Жаккара. Для масштабирования процесса на миллионы примеров используется локально-чувствительное хеширование (LSH): сигнатура каждого документа ($k$ хешей) разбивается на $r$ корзин, в каждой из которых по $b$ хешей; затем хеши внутри каждой корзины объединяются в одно значение, и если у двух документов совпадает значение хотя бы в одной корзине, они признаются потенциальными дубликатами. Отобранные пары фильтруются по значению Edit Similarity (в нашем случае данный фильтр опциональный), после чего похожие документы объединяются в кластеры методом поиска связных компонент, и лишние копии удаляются.

## Аргументы функции

- `chunks: List[Chunk]` - список чанков для фильтрации;
- `config: Config` - конфиг.

## Работа со скриптами

Пример использования:

```
from src.filtering.neardup.main import neardup_pipeline

filtered_chunks = neardup_pipeline(chunks, config)
```

Возвращает `List[Chunk]`. Также сохраняет отобранные чанки в `"./src/filtering/neardup/output"`.
