## Принцип работы

Фильтрует текстовые чанки с помощью обученной модели классификации (Random Forest), предварительно обученной на разметке от LLM. Модель оценивает «учебниковость» текста — насколько чанк похож по стилю и структуре на качественный учебный материал, и сохраняет только высококачественные фрагменты.

---

## Параметры инициализации

- `embedding_model: EmbeddingModel` — модель для генерации эмбеддингов текста
- `classifier_path: str | None = None` — путь к предобученной модели классификатора (если `None` — обучается автоматически)
- `embedding_path: str | None = None` — путь к кэшированным эмбеддингам
- `annotation_path: str | None = None` — путь к файлу с разметкой от LLM
- `sample_size: int = 1000` — размер подвыборки для обучения классификатора
- `train_ratio: float = 0.8` — доля обучающей выборки при сплитовании

---

## Алгоритм

Для фильтрации вызывается метод `TextbooksQAFiltration.filter(chunks: List[str])`, который выполняет следующие шаги:

### Подготовка данных
1. Для каждого чанка генерируются эмбеддинги с помощью `embedding_model`.
2. Эмбеддинги кэшируются в файл для ускорения повторных запусков.

### Обучение модели (при отсутствии предобученной)
3. Из исходного набора извлекается случайная подвыборка размером `sample_size`.
4. Подвыборка разделяется на обучающую и тестовую части в соотношении `train_ratio`.
5. Каждый чанк из подвыборки размечается LLM с помощью промпта из `prompts.py`: метка `1` — качественный учебный текст, `0` — низкокачественный.
6. Разметка кэшируется в файл для повторного использования.
7. Обучается `RandomForestClassifier` на парах (эмбеддинг, метка); модель сохраняется в `classifier_path`.

### Фильтрация
8. Обученная модель применяется ко всем чанкам набора данных.
9. Сохраняются только чанки с предсказанной меткой `1` (качественные учебные фрагменты).
10. Возвращается отфильтрованный список текстов.
