## Принцип работы

Фильтрует текстовые чанки с помощью обученной модели классификации (Random Forest), предварительно обученной на разметке от LLM. Модель оценивает «образовательную ценность» текста — является ли текст качественным учебным материалом, и сохраняет только высококачественные фрагменты.

---

## Параметры инициализации

- `subsample_size: int = 1000` — количество случайно выбранных текстовых фрагментов для разметки и обучения классификатора, если предобученная модель отсутствует.  
- `llm_url: str = "http://vllm:8000/v1"` — базовый URL сервиса LLM, используемого для разметки текстов.  
- `llm_model: str = "unsloth/gemma-3-12b-it"` — название языковой модели, применяемой для генерации разметки.  
- `embedding_url: str = "http://vllm:8001/v1"` — базовый URL сервиса эмбеддингов для векторизации текстовых фрагментов.  
- `embedding_model: str = "Qwen/Qwen3-Embedding-0.6B"` — название модели эмбеддингов.  
- `embeddings_path: str = "data/embeddings.npy"` — путь для загрузки или сохранения эмбеддингов (в формате NumPy `.npy`).  
- `annotations_path: str = "data/annotations.joblib"` — путь для загрузки или сохранения разметки, сгенерированной LLM.  
- `limit_labels: int = 20` — максимальное количество размеченных примеров, используемых при обучении.  
- `models_path: str = "data/models"` — директория для сохранения или загрузки обученных моделей классификатора.  
- `datasets_path: str = "data/datasets.npz"` — путь для сохранения или загрузки обучающей и тестовой выборок (в формате NumPy `.npz`).  
- `metadata_path: str = "data/metadata.json"` — путь для сохранения метаданных обучения (метрики и т.д.) в формате JSON. 
- `save_metadata: bool = False` — флаг, определяющий, сохранять ли метаданные обучения в файл.  
- `test_size: float = 0.2` — доля данных, выделяемая для тестирования (значение от 0.0 до 1.0).  
- `random_state: int = 42` — seed для обучения модели.

## Алгоритм

Для фильтрации вызывается метод `EducationValueClassifierFilter.apply(chunks: List[Chunk])`, который выполняет следующие шаги:

1. Для каждого чанка генерируются эмбеддинги с помощью `embedding_model`.
2. Эмбеддинги кэшируются в файл для ускорения повторных запусков.
3. Из исходного набора чанков извлекается случайная подвыборка размером `sample_size`.
4. LLM размечает выбранные чанки до тех пор, пока не будет собрано ровно limit_labels//2 примеров для каждого класса (0 — низкокачественный, 1 — качественный учебный текст). Это обеспечивает баланс классов в обучающей выборке.
5. Разметка кэшируется в файл `annotations_path` для повторного использования.
6. Подвыборка с полученными от LLM метками разделяется на обучающую и тестовую части в соотношении (1 - test_size) : test_size.
7. Обучается `RandomForestClassifier` на парах (эмбеддинг, метка); модель сохраняется в `models_path`.
8. Обученная модель применяется ко всем чанкам исходного набора данных.
9. Сохраняются только чанки с предсказанной меткой `1` (качественные учебные фрагменты).
10. Возвращается отфильтрованный список текстов.
