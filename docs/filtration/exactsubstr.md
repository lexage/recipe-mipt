## Принцип работы

Обнаруживает и удаляет точные дубликаты подстрок заданной минимальной длины в коллекции текстовых чанков с помощью суффиксных и LCP массивов.

---

## Параметры инициализации

- `threshold: int` — минимальная длина подстроки-дубликата для удаления

---

## Алгоритм

Для дедупликации вызывается метод `ExactSubstrFiltrator.apply(chunks: List[str])`, который выполняет следующие шаги:

1. Каждый текстовый чанк преобразуется в байтовую последовательность согласно указанной кодировке.
2. Все байтовые последовательности конкатенируются в единую строку с разделителем `b'\x00'` между чанками; фиксируются смещения и длины исходных чанков.
3. Строится суффиксный массив конкатенированной строки алгоритмом `divsufsort` для эффективного поиска подстрок.
4. Вычисляется LCP-массив (Longest Common Prefix) алгоритмом Касаи для определения длин общих префиксов соседних суффиксов.
5. Создаётся карта принадлежности позиций к исходным чанкам для отслеживания источника каждой подстроки.
6. Анализируются значения LCP-массива: при обнаружении общей подстроки длиной ≥ `threshold` проверяется, что:
   - Подстрока расположена в разных чанках
   - Позиции не пересекают разделитель
   - Один из чанков не является первым в списке (первый чанк всегда сохраняется)
7. Для каждого «более позднего» чанка помечаются интервалы байт для удаления; перекрывающиеся и смежные интервалы объединяются.
8. Из байтового представления чанков удаляются помеченные участки, оставшиеся байты декодируются обратно в текст.
9. Пустые после обработки чанки исключаются из результата; возвращается список очищенных текстов.
