## Принцип работы

Обнаруживает и удаляет точные дубликаты подстрок заданной минимальной длины в коллекции текстовых чанков с помощью суффиксных и LCP массивов.

---

## Параметры инициализации

- `threshold: int` — минимальная длина подстроки-дубликата для удаления

---

## Алгоритм

Для дедупликации вызывается метод `ExactSubstrFiltrator.apply(chunks: List[Chunk])`, который выполняет следующие шаги:

1. Каждый текстовый чанк преобразуется в байтовую последовательность согласно указанной кодировке (UTF-8).
2. Все байтовые последовательности конкатенируются в единую строку с уникальными разделителями между чанками.
3. Строится суффиксный массив конкатенированной строки алгоритмом `divsufsort` для эффективного поиска подстрок.
4. Вычисляется LCP-массив (Longest Common Prefix) алгоритмом Касаи для определения длин общих префиксов соседних суффиксов.
5. Создаётся карта принадлежности позиций к исходным чанкам (`total_doc_ids`); позиции разделителей помечаются значением `-1`.
6. Анализируются значения LCP-массива: при обнаружении общей подстроки длиной ≥ `threshold` проверяется, что:
   - Подстрока расположена в **разных** чанках (`doc_id1 != doc_id2`)
   - Обе позиции находятся внутри чанков (``)
   - Длина совпадения ограничена границами «удаляемого» чанка
7. Для пары дублирующихся чанков **сохраняется чанк с меньшим индексом**, а из чанка с большим индексом помечается интервал байт для удаления. Если дубликат покрывает весь чанк — он удаляется целиком.
8. Перекрывающиеся и смежные интервалы внутри одного чанка объединяются.
9. Из байтового представления чанков удаляются помеченные участки, оставшиеся байты декодируются обратно в текст.
10. Чанки, текст которых после `strip()` становится пустым, исключаются из результата; возвращается список очищенных текстов.
