## ⛔ Правило по серверам — только `alibaba`, и только командами

**Единственный сервер, с которым Claude работает, — кластер `alibaba`**
(узел `ali117197`, `vizilter@10.0.117.197`, псевдоним `alibaba` в ssh-config
WSL). Доступ только через корпоративный VPN.

С 25.09 работа на узле **автономная**: «запускай, пиши как получается, если
что-то падает — исправляй». Разрешено:

- отдельные **неинтерактивные команды** (`ssh alibaba '<команда>'`): запуск
  прогонов, чтение логов и результатов, постановка и снятие **своих** заданий;
- доставка файлов репозитория rsync-ом из WSL — только отслеживаемые git

- долгие прогоны на узле запускать через `setsid nohup … &` с логом в
  `self-service-filtration_generation-eval/logs/`, чтобы обрыв ssh их не убивал.

Запрещено:

- **любые другие серверы**, в том числе старый `VizilterK@proxy2.cod.phystech.edu`;
- интерактивные сессии на узле: оболочки, редакторы, `top`, всё, что ждёт ввода;

  учётной записью `vizilter` идут чужие задания (`liars-*`) — не трогать;
- удаление чего бы то ни было без прямого указания;
- действия, отнимающие ресурсы у других, — только с явного разрешения.

**Связь с узлом пропала** (ssh timeout) → проверить VPN:
`Find-NetRoute -RemoteIPAddress 10.0.117.197` в PowerShell — маршрут должен
идти через интерфейс `VksPersonal-2.0` (WARP и AdGuard — не то). VPN включён —
стучаться дальше, пока не ответит; выключен — написать Konstantin.

## 🚫 Никаких смоук- и пробных прогонов

Никогда не гонять пайплайн на части задач или части корпуса (`--limit`,
`--max-docs`, «проверка стенда»). **Только полные эксперименты** — 1000 задач
DS-1000, весь корпус. Проверки без прогона пайплайна (проверка ввода,
восстановление, отдельная фильтрация, отдельная генерация, одиночный запрос к
модели для диагностики) допустимы.

## ⌨️ Как подавать команды Konstantin

Каждая команда — **в отдельном блоке кода, строго по одной**. **Внутри блока —
никаких комментариев**, только сама команда; пояснения обычным текстом до или
после. Не склеивать команды через `&&` и переносы, не придумывать лишних шагов.

## 📏 Прочие правила, про которые легко забыть

- **Методы не трогать**: фильтр `api_genre` и генератор `prompt_rules` готовы;
  скрипты их только вызывают, не дописывают и не переписывают.
- **Каждый эксперимент самодостаточен**: внутри него свой бейзлайн, дельта
  меряется к нему. Никогда не заявлять, что числа «несравнимы».
- **Инициативу не проявлять**: на вопрос отвечать ответом, а не действием;
  делать ровно то, о чём попросили; на остальное спрашивать разрешение.
  Исключения: `Progress.md` (обновлять всегда) и автономная работа на
  alibaba в рамках текущей задачи.
- **Вопросы задавать свободным текстом**, без списков с вариантами выбора.
- **Ничего не утверждать без проверки**: либо проверено на данных, либо названо
  гипотезой со способом её проверить.
- **Порт/модель не брать из заметок**: перед прогоном проверить `/v1/models`
  (`./scripts/launch-test-models.sh --status`).
- **Не всё сразу**: сейчас ПМИ; НТО — после ПМИ.
- Коммиты — локально; пушит Konstantin.
- **Одноразовые инструменты** (генераторы docx/pdf, рендер Word, скрипты
  правок) создавать вне репозитория и удалять сразу после использования —
  всегда. В `docs/` не должно быть `.py`; в `docs/pmi/out`, `docs/nto/out` —
  только готовые docx/pdf.
- **Архив pk3.zip — только то, что нужно для испытаний по ПМИ** (белый список
  в `Progress.md`): никаких заметок, `docs/`, экспериментальных конфигов,
  инструментов сборки.
- **Ни одного слова `recipe`** в ПМИ, архиве и на стенде (каталоги, скрипты,
  контейнеры, venv, формат корпуса) — тотальное переименование, план в
  `Progress.md` («ПМИ v3»). Никаких «оставляю как есть».
- **Не спорить с решениями Konstantin по содержанию** (например, «пересказ —
  не эталон»); сомнение высказать один раз, коротко.

### Грабли кластера

1. **Образ перезаписывает переменные окружения своим профилем.** Индекс pip и
   адрес хаба задавать флагами командной строки; логин-шелл в контейнере не
   использовать. `docker run` без `-i` не передаёт stdin — код в контейнер
   подавать через `python -c`.
2. **Квота 120 ГБ ОЗУ на все задания учётной записи сразу**, в том числе
   чужие (`liars-*`, по 24 ГБ). Иначе задание висит с `AssocGrpMemLimit`.
   Решатель фактически занимает ~11 ГБ → `LLM_MEM=64G`. **Эмбеддеру нужно
   24 ГБ**: с 8 ГБ он падает с `CUDA error: invalid argument`.
3. **`bin/python` в venv — ссылка на интерпретатор контейнера**, с узла выглядит
   битой; проверять venv по `bin/activate`.
4. **Модели — в короткой очереди `prims`, лимит 4 ч** (`MODELS_PARTITION`,
   `MODELS_TIME`). Полный эксперимент должен уложиться в оставшееся время
   заданий моделей (`squeue -u $USER`, TIME_LEFT); иначе перезапустить модели.
   Длинная очередь вытесняема короткой.
5. **Физическую карту выбрать нельзя**; задание может ждать `Resources`.
6. **Имя модели в API — путь к весам**: решатель грузит по нему токенайзер.
7. **Qwen3.x рассуждает по умолчанию** — `enable_thinking: False` у решателя,
   генератора правил и выбора API (без него `APISelector` исчерпывает 256
   токенов рассуждением и не называет API).
8. **Перезапуск моделей после `scancel`** — дождаться исчезновения задания из
   squeue, иначе launch-test-models будет ждать снимаемое задание.
9. Каждый прогон должен строить индекс с нуля (существующий каталог индекса
   переиспользуется без пересчёта) — `run-evaluation.sh` делает свежий каталог
   в каталоге прогона.

### Грабли кода

1. **Не писать `from __future__ import annotations`** в файлах компонентов:
   реестр читает конкретные аннотации.
2. **Новый компонент регистрируется в `src/pipelines/constants.py`**, новый
   пайплайн — ещё и в `src/pipelines/templates/__init__.py`.
3. **Фабрика перебирает параметры класса, а не конфига**: лишний ключ в YAML
   молча игнорируется (`standalone.py` в отдельных запусках такой ключ
   отвергает).
4. **`model_name` у решателя игнорируется** — модель берётся с эндпоинта.
5. **`enchancer` в конфигах exp13–17 — опечатка** (`enhancer`); задним числом не
   «чинить».
6. **Индекс на конфиг**: конфиг, меняющий корпус, — свой `path_to_vector_db`.
7. **Локальный qdrant держит блокировку на каталог индекса** — конфиги гонять
   последовательно.
8. `src/db/docs_db/__init__.py` импортирует `LocalDB` (qdrant) — лёгкие модули
   класть вне этого пакета (как `src/db/json_corpus.py`).
9. Правка файлов WSL через `\\wsl.localhost\…` сбрасывает бит исполнения у
   скриптов — перед коммитом `chmod +x self-service-filtration_generation-eval/scripts/*.sh`
   (и вернуть +x файлам, у которых он есть в индексе git).
