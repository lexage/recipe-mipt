# Метод фильтрации из статьи Textbooks are all you need

## Структура репозитория

``` markdown
├── src/                     # Основные классы и функции
│   ├── get_embedding.py     # Класс для формирования эмбеддингов
│   ├── label.py             # Класс для разметки данных
│   ├── prompts.py           # Промпты
│   ├── random_forest_cls.py # Класс для работы с RandomForestClassifier
│   └── utils.py             # Вспомогательные функции
├── experiments_ds1000       # Папка со скриптами запуска экспериментов на наборе данных DS-1000
└── main.py                  # Основной скрипт запуска
```

## Алгоритм фильтрации

Алгоритм разделен на три этапа: подготовка данных, обучение модели и фильтрация с помощью обученной модели.

### Этап подготовки данных

1. Загрузка исходного набора данных
2. Формирование эмбеддингов для исходного набора данных (если эмбеддинги уже существуют, они загружаются из файла)

### Этап обучения

Если обученная модель уже существует, данный этап пропускается.

1. Из исходного набора данных извлекается подвыборка и разделяется на обучающую и тестовую выборки
2. Получение автоматической разметки с помощью LLM (если разметка уже существует, она загружается из файла)
3. Обучение RandomForestClassifier на размеченном наборе данных и сохранение полученной модели

### Этап фильтрации

1. Загрузка обученной модели классификации
2. Получение меток классификации для набора данных
3. Возврат данных с меткой "1" (качественные данные)
