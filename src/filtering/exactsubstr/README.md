# Метод фильтрации из статьи Deduplication Training Data 

## Структура репозитория

``` markdown
├── experiments_ds1000      # Папка со скриптом запуска экспериментов на наборе данных DS-1000
├── test                    # Папка со скриптом для тестирования
├── requirements.txt        # Файл для установки необходимых зависимостей
└── main.py                 # Основной скрипт запуска
```

## Алгоритм фильтрации

1. **Конвертация в байты**:
   - Каждый текстовый чанк преобразуется в байтовую последовательность
   - Поддерживается два режима:
     * UTF-8 кодирование (по умолчанию)

2. **Конкатенация чанков**:
   - Все байтовые последовательности объединяются в единую строку
   - Между чанками вставляется разделитель `b'\x00'`
   - Фиксируются смещения начала каждого чанка и их длины

3. **Построение служебных массивов**:
   - **Суффиксный массив** строится алгоритмом `divsufsort` для эффективного поиска подстрок
   - **LCP массив** (Longest Common Prefix) вычисляется алгоритмом Касаи для определения длин общих префиксов соседних суффиксов
   - **Карта принадлежности чанков** создаётся для отслеживания позиций каждого чанка в конкатенированной строке

4. **Поиск дубликатов**:
   - Анализируются значения LCP массива для обнаружения повторяющихся подстрок
   - Дубликаты регистрируются только если:
     * Длина подстроки ≥ заданного порога (`threshold`)
     * Подстрока находится в разных чанках
     * Позиции не пересекают разделители
   - Для каждого дубликата определяется "более поздний" чанк (по порядку в списке), из которого будет произведено удаление

5. **Обработка интервалов**:
   - Для каждого чанка собираются интервалы байт для удаления
   - Перекрывающиеся и смежные интервалы объединяются
   - Из байтового представления удаляются помеченные участки
   - Оставшиеся байты декодируются обратно в текст

6. **Особенности обработки**:
   - Первый чанк в списке всегда сохраняется без изменений
   - Удаляются только дубликаты из более поздних чанков
   - Пустые после обработки чанки исключаются из результата
   - Разделитель гарантирует отсутствие пересечений подстрок между чанками

## Тестирование

Для тестирования необходимо перейти в папку `test` и выполнить команду:

```bash
python test.py
```

## Запуск экспериментов на наборе данных DS1000

Для запуска экспериментов необходимо перейти в папку `experiments_ds1000` и выполнить команду:

```bash
python run.py --data_path /workspace/data/docs_database.db
```
