## Мелочи

- `SQLiteDocsDBAdapter.id_offset` = число документов; в отфильтрованной БД id
  разрежены — при `index_sources: [examples]` или `return_examples: True` id
  примеров могут совпасть с id документов. В конфигах фильтрации ПМИ не
  задействовано (в `apis.db` так же).
- Раннер вызывает `pipeline.run(task.prompt)` — строку; `APIRetriever` на строке
  получает пустые метаданные, ограничение по библиотеке задачи не срабатывает
  (по коду; так было и в exp7).
- Журнал `--log-chunks` не пишет имя запрошенного API.
- В git давно лежит `.env` в корне с шаблонными значениями; в pk3.zip не идёт.
- Правка файлов WSL через путь `\\wsl.localhost\…` сбрасывает бит исполнения
  у скриптов — перед коммитом `chmod +x recipe-mipt-eval/scripts/*.sh`.
- Решатель exp7 работает через `api: completions` — на Qwen3.6 отвечает
  (стенд прошёл), качество покажет полный прогон.
